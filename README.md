# BENCH: One versus Many

BENCH, or the Bayesian EstimatioN of CHange framework, was created by Dr. Hossein Rafipoor to estimate microstructural differences between groups.
While an effective technique for traditional research frameworks, clinicians may benefit from using this tool to investigate differences in a patient from the healthy norm (one versus many). 
This repository provides a pipeline for preprocessing and running this analysis. This work was shared in the 2026 ISMRM Workshop on White Matter: MR Imaging and Beyond.

## How to use BENCH
A tutorial for running the standard technique can be found [here](https://pages.fmrib.ox.ac.uk/fslcourse/practicals/bench/index.html).
